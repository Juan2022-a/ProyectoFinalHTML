# Sistema para elaboración de recetas de cocina 🍳

Aplicación web interactiva para sugerir recetas caseras basadas en los ingredientes disponibles en casa, diseñada con una interfaz minimalista, selector de tema claro/oscuro y soporte para despensa rápida, porciones y pasos interactivos.

## Requisitos previos

Para ejecutar este proyecto de forma local en tu computadora, necesitas tener instalado:
* **XAMPP** (o cualquier entorno que incluya un servidor web con soporte para PHP).

---

## Instrucciones de Instalación y Ejecución

1. **Clonar o colocar el repositorio:**
   * Descarga o clona el proyecto dentro de la carpeta `htdocs` de tu instalación de XAMPP. La ruta exacta debe ser:
     ```text
     C:\xampp\htdocs\xampp\ProyectoFinalHTML\
     ```

2. **Iniciar el servidor local:**
   * Abre el **Panel de Control de XAMPP**.
   * Inicia el servicio de **Apache** (y MySQL si el proyecto lo requiere para algún almacenamiento adicional).

3. **Ejecutar la aplicación:**
   * Abre tu navegador web de preferencia.
   * Ingresa a la siguiente URL para cargar el sistema[cite: 1]:
     ```text
     http://localhost/xampp/ProyectoFinalHTML/Main/
     ```

---

## Características del Sistema

* **Búsqueda inteligente por ingredientes:** Escribe lo que tienes en casa o selecciónalo rápidamente mediante los botones de la despensa rápida.
* **Control de restricciones:** Excluye alergias o ingredientes que no deseas consumir.
* **Filtro de prioridades:** Prioriza recetas exactas con tus ingredientes y deja al final opciones con acompañantes extra.
* **Modo Oscuro / Claro:** Diseño adaptado con una paleta de colores cálida y profesional basada en psicología del color culinaria.
* **Checklist de cocina interactivo:** Tacha los pasos de preparación conforme vas cocinando.
* **Calculador de porciones:** Ajusta automáticamente las cantidades sugeridas para 1, 2 o 4 personas.
* **Historial y Recetas Guardadas:** Almacena tus platillos favoritos localmente en el navegador.
